### F1 — P2: неполная проверка физических параметров профиля позволяет обратную тягу и отказ первого ввода

Место: `client/src/tuglab2/train.ts:62` (проверка при создании), `client/src/tuglab2/train.ts:27` (валидатор состояния).

`createTrain` проверяет геометрию, массу, четыре силы/момент и три `speedLimits`, но не проверяет поля унаследованного `SpaceProfile`, используемые штатным FA. `validTrainState` тоже считает такой профиль допустимым.

Воспроизведение на Node 20.20.2:

1. `cfg = createDefaultTrainConfig(); cfg.ships.A.crewGLimit = -1; s = createTrain(cfg)` — создание успешно, `validTrainState(s) === true`.
2. `spaceEngineWrench(s.bodies.A, {forward:1,lateral:0,yaw:1,brake:false,action:false,toggleFA:false}, true, trainSpaceProfile(s.config,'A'), 1/60)` выдаёт `force.x = -3935772` Н.
3. Применение этого wrench через `advanceTrain` принимает тик без `stopReason`; A получает `vx = -0.16051819306505022` м/с. Команда вперёд приводит к движению назад.
4. Аналогично `yawLimit = NaN` и `speedLimit = -1` принимаются при старте, но первая команда создаёт NaN wrench и останавливает опыт с ошибкой «Недопустимая внешняя сила».

Нарушен §5.3: до старта должны проверяться допустимые физические параметры. Нужна единая проверка конечности/знака полей всех профилей A/B/C с сохранением разрешённых нулевых значений там, где ноль имеет смысл. Тестировать атомарный отказ, а не позднюю остановку после принятия конфигурации. Код прежнего FA изменять не требуется.

### F2 — P2: стандартную AB нельзя снова сцепить после отключения на паузе

Место: `client/src/tuglab2/train.ts:107`.

Воспроизведение:

```js
const s = createTrain(createDefaultTrainConfig());
const detached = setTrainConnection(s, 'AB', false).state;
const result = setTrainConnection(detached, 'AB', true);
```

В стандартном M–L–M `trainConnectionGeometry(detached, detached.connections[0]).distance` равно `360.00000000000006`, а `captureMaxLength` равно `360`. Строгая проверка `distance > c.captureMaxLength` отвергает обратный захват с сообщением «Крепления вне диапазона захвата от 2 м до LAB-предела модуля». Мир и скорости вообще не менялись между вызовами. Это нарушает включительную верхнюю границу захвата и AC-10. Также воспроизведено для S–S, S–L, M–S, L–S.

Нужно сравнение min/max с малым масштабированным допуском численного округления. Фактическую длину успешного захвата сохранять. Проверить значение точно на обеих границах и реально выходящее за них.
