# TugLab-2 — план реализации

**Цель:** играбельный поезд A–B–C в отдельной космической лаборатории с честным ограниченным ассистентом и повторяемыми опытами.
**Архитектура:** отдельные модули `client/src/tuglab2/`, чистые профили U2TagLab, общий транзакционный шаг всех тел/связей/контактов, контроллер принятого тика и запись; оболочка Preact/Canvas. Общие старые модули сохраняются.
**Стек:** TypeScript, Preact, Canvas 2D, Vite5, существующий node:test.
**ТЗ:** `docs/tz/spec_u2_tuglab2_v0.1.md` (согласованное f5cfdbea; перенесено cherry-pick -x).
**Исполнение:** Developer-агенты последовательно, независимые Reviewer/QA. Повторное утверждение плана отменено прямым поручением оператора. Учёт только Beads; этот документ задаёт решения/контракт, не заменяет задачи.

## Общие ограничения
Русские комментарии; английские идентификаторы. Только пружины. Прямоугольная инерция и круг R из U2TagLab. Силы взаимны в креплениях. Один общий шаг B. C получает только обычный wrench двигателей, без маршевой тяги и собственного FA. Физика/история/запись изменяются лишь на принятом тике. На отказе возвращается последний конечный принятый мир. Массы, корпуса, двигатели и связи меняются атомарным новым стартом на паузе. Производственных изменений, merge/release/deploy нет.

## Риски для проверки
Повреждённый/чужой/неограниченный JSON; потеря focus/pointer при торможении; слишком короткий/непомещающийся старт; накат против отсутствующего C; потеря времени/истории при solver retry. Проверки относятся соответственно к этапам 2/3/1/1/2.

Result содержит state, contacts, diagnostics, stopReason?. Экспортировать default config и клонирование; два состава train/single. Конкретные поля зафиксировать в types и сообщить следующему Developer.

## Verification Contract — зафиксирован до опытов
Допуски AC16–22 сохраняются из ТЗ без ослабления. Характерная длина=max исходных радиусов и l0. P/L нормируются max(|initial|,sum m*characteristicSpeed / sum(m*r*v+I*w)), также абсолютная ошибка для zero. Энергия всех динамических тел; выключенные двигатели/поля/контакты и неактивные пределы для инвариантов. Частоты физики30/60/120; браузерный RAF не задаёт physics dt. Контроллерная история не меняется при откатах.

До серии AC23 фиксируется определение основных метрик: боковой уход B — расстояние от исходной линии состава через центр A вдоль его начального носа; угловое отклонение B — абсолютный развёрнутый угол B относительно этого начального направления. Начальные 0.1RB и ±5° входят в метрики. Текущие относительные углы B–A/B–C показываются дополнительно и не заменяют основное угловое отклонение.
