# План реализации U2 TugLab — минимальное расширение BonkLab

> **Исполнителям:** `superpowers:subagent-driven-development`, PM координирует реализацию и независимое review. Учёт и статусы — только Beads.

**Цель:** дать оператору поиграть на оригинальной карте BonkLab с прицепом и подобрать параметры трёх сцепок, их длины и жёсткости пружины.

**Архитектура:** явно включаемый режим `BonkLab(canvas, { towing: true })`, отдельная HTML-оболочка/статическая сборка с тем же `src/lab/main.ts`. Сохраняются генератор, штатные Flight Assist/параметры движения, мышь/сенсорный джойстик, панель, камера, препятствия, поверхности, орбы и финиш. Добавляются пассивный B, слой сцепки и численный расчёт пары. `/lab` по умолчанию использует прежний путь.

**Стек:** существующие TypeScript, Vite, Preact, Canvas; `node:test` для физики. Новые продуктовые зависимости не нужны.

**Источники:** [PR #35](https://github.com/komleff/bonk-race/pull/35), [исходное ТЗ](../../tz/spec_u2_tuglab_v0.1.md) и последние указания оператора 2 октября 2026. Оператор ранее согласовал план и выполнение; после паузы написал «продолжай». Эта редакция устраняет отменённые требования; дополнительное разрешение на обычную реализацию не требуется.

## Обязательные изменения объёма

- Максимально переиспользовать bonk-race, переделывать минимум. Прежний план нового runtime/набора сцен/нового управления заменён этой редакцией.
- Запись, export/import, replay и исследование с пятью игроками исключены. В режиме TugLab скрыть штатные кнопки обмена параметрами; BonkLab сохранить.
- Штатные масса/радиус A, силы, сопротивление, зоны и FA остаются настраиваемыми через существующий LabPanel. Не подменять их фиксированными массой 10000 кг/радиусом 6 м и six-DOF двигателями раннего прототипа. Клавиатура WASD/стрелки даёт направление в мировых осях, как raceMain, а не отдельные боковые двигатели.
- Три сцепки: штанга — целевая длина, трос — максимальная, пружина — длина покоя. Длина между точками крепления. Обязательный отдельный параметр пружины — `k`, Н/м; частота не заменяет жёсткость.
- Новая группа `tow.*`: масса B/A 0.1–10 (быстрые 0.1/0.25/0.5/1/2/5/10), радиус B 2–60 м (по умолчанию 20), длина 4–24 м (8), тип spring, жёсткость 0–10000 Н/м (1250), damping ratio 0–1.5 (0.5). Начальная опорная масса демпфирования A/2 фиксируется на Restart; изменение массы B не перенастраивает c. Для изолированного ядра сохраняется отдельный конфиг U2 и более широкий валидный k.
- Изменение параметров прицепа/сцепки не меняет seed/препятствия и не телепортирует тела. Масса/радиус меняют инерцию B; тип/длина сбрасывают solver cache. Restart явно возвращает состав на старт.
- Генератор `shared/src/physics/arenaGenerator.ts` не изменяется и не заменяется адаптером нейтральных объектов. Стартовый состав проверяется целиком: исходный spawn всего 50 м от нижней стены, при необходимости локально сдвинуть состав внутрь свободной стартовой области. Для неподходящих размеров — понятная ошибка, без изменения карты.
- Финиш штатный по A; новые bay/доставка/многосценный селектор не нужны. Шипы/орбы сохраняются; при гибели любого тела рестартуют оба через штатный отсчёт.
- Изолированные проверки P/L выполняются без внешних сил. Игра со штатным сопротивлением, FA, зонами и неподвижными препятствиями не обязана сохранять импульс пары. AC оригинального ТЗ по изменённым сценам/двигателям/управлению явно отмечаются как заменённые требованиями оператора, без фиктивного PASS.

## Общие ограничения

- Worktree `/Users/komleff/Documents/GitHub/bonk-race-tuglab`, ветка `feat/u2-tuglab-v0.1`, draft PR #36 на базе PR #35. No main push/force push/agent merge.
- Комментарии в коде на русском, идентификаторы английские. Существующие workflows публикации BonkLab не изменять; TugLab имеет отдельный output с относительными ресурсами.
- Численный тик 60 Гц; 30 Гц проверяется в изолированном ядре. Бюджет подшагов ограничен; при исчерпании вернуть последний валидный мир/видимую причину, без туннелирования и NaN.
- Взаимные импульсы в точках крепления, инерции двух дисков независимы. Штанга сохраняет P/L в свободном движении и удерживает длину в пределах 1%; трос не толкает в свободном состоянии; пружина прикладывается один раз за подшаг, упоры не пропускаются.
- Каждый подшаг перемещает тела ровно один раз. Stock `integratePhysics` может использоваться в callback для получения новых скоростей, а движение выполняется общим drift/CCD. История yaw обновляется один раз на основной тик, не по числу адаптивных подшагов.
- Линия сцепки без коллайдера; допустимо её визуальное пересечение с препятствием. Контакты A/B, кругов и стен учитываются для обоих тел; орбы интегрируются один раз за основной интервал.
- Базовая регрессия: существующие `npm test`, `npm run build`, `npm run build:lab --workspace=client`, `npm run check-version`.
- Реальный Android и публикация учитываются отдельно; desktop/touch emulation не объявляются проверкой физического планшета.

## Основное внимание review

1. Валидные поперечные скорости/малые длины не растягивают штангу молча; ограниченный расчёт и атомарный отказ.
2. Изменение массы/радиуса/жёсткости, особенно около контакта, сохраняет валидные тела/карту; пустое или NaN поле не меняет настройки.
3. Restart/респаун/новая карта синхронно сбрасывают A/B/сцепку/ввод/интерполяцию; орбы не шагают дважды.
4. Тач и мышь остаются штатными; blur/cancel/ввод текста не оставляют тягу. Физическая история FA не зависит от числа подшагов.
5. `/lab` проходит прежний путь; новая физика, новый UI и клавиатура включены только в TugLab. Статический output работает в корне и вложенном пути без серверного API.
