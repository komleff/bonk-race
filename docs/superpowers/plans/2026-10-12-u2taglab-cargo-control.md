# Корректировка заднего пилота и финиша U2TagLab

Основание — прямые уточнения оператора после поставки30d1d6a. Реализовать в существующих стендах, без новой оболочки. .8 — задний пилот, .12 — зачёт финиша.

## Задний пилот

C ориентирован вперёд, носом к хвостовому креплению B; B пассивен. Сохраняются старые управление A/карта/камера/solver и реальные профили двигателей. Предыдущая модель наблюдала только относительные B/C ошибки и не распознавала общий боковой снос. Начальный контроллер заменяется причинной памятью уже принятого пути A: ограниченная polyline, последовательный прогресс B, цель на историческом участке вместо мгновенного направления ведущего. Track строится только из принятых состояний, сохраняется при паузе/смене mode, очищается Restart; отказ шага не добавляет историю.

Наблюдаемые ошибки груза/цели C проходят установленную задержку. Guard гасит уход через реальную BC силу; brake по запросу тормоза A либо заднего тормоза добавляет торможение скорости B. C тормозит ретродвигателями, не разворачивается задом наперёд. Направление фактической retro проверяется при приложении силы; запрещены скрытая сила B, прямое изменение скорости/угла, FA C, усиление профиля или изменение evaluator ради результата. Журнал поддерживает strict optional track group; replay применяет принятые команды, causal recompute строит тот же accepted path.

RED перед фиксом: общий боковой B/C drift, перевёрнутый C как аварийный контрпример, delayed зеркальный поворот по уже пройденному пути A и rear-only торможение B при отсутствии Brake A. Сохранить исходные и новые одинаковые inputs, side/angle/path/residual/contacts, ограничения и отрицательные исходы. Полная численная матрица после проверки полезности целевых случаев; старые данные не переписывать.

## Зачёт финиша

TugLab и U2TagLab AB/ABC: только центр B пересекает finish.y в направлении финиша, внутри прежней ширины полосы. Swept пересечение между принятыми позициями исключает пропуск черты на большом шаге; A впереди и C позади не влияют на зачёт. Обычный BonkLab без буксировки остаётся прежним. RED/GREEN для раннего A, B crossing/Cbehind, off-width, обратного движения, overshoot и одноразового finish time/best record.
