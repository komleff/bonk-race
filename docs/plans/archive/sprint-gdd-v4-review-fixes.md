# План: Правка GDD v4.0 по ревью PR #10

## Контекст

PR #10 получил 12 inline-комментариев + 2 развёрнутых обзора (геймдизайнер, GPT-5 Codex). Также оператор задал принципы оформления:

1. **Язык:** только русский, без жаргона и англицизмов
2. **Термины:** технические идентификаторы (переменные, классы, файлы) — на английском в backticks
3. **Глоссарий:** все использованные термины описать в глоссарии
4. **Стиль:** кратко, по делу, без вводных слов
5. **Содержание:** только логика, требования и архитектура словами. Примеры кода и конкретные реализации запрещены
