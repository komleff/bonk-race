# TugLab-2 — проверка на физическом Android

Этот сценарий не является результатом проверки. До запуска на реальном устройстве `bonk-race-tug2.5` и Android-часть AC-13 остаются открытыми. Desktop Chrome и эмуляция сенсорного экрана учитываются отдельно.

## Запуск

На компьютере с Node20 из корня checkout:

```sh
npm ci
npm run build:pages
python3 -m http.server 5177 --bind 0.0.0.0 --directory client/dist-pages
```

Планшет и компьютер должны быть в одной сети. Открыть `http://<LAN-IP-компьютера>:5177/tuglab2/` в Chrome. Для текущего стенда адрес — `http://192.168.68.65:5177/tuglab2/`. Сервер должен оставаться запущенным. Записать модель устройства, Android/Chrome, размер экрана, ориентацию, исходный SHA сборки и дату.

## Сценарий, около пяти минут

1. Проверить стартовую паузу, три корпуса A/B/C и обе связи. Панель не должна перекрывать область пилотирования; кнопки AB, BC, тормозов и масштаба доступны в портретной и альбомной ориентации.
2. Начать полёт. Сенсорным джойстиком дать мировое направление вправо, затем вверх. A должен реагировать, B и C двигаться через пружины. Увеличить и уменьшить масштаб, включить камеру всего состава.
3. В «Накате» проверить нулевые ретро, бок и поворот C. Включить «Страховку», g=50%, задержку1с; проверить видимые ограниченные команды. При g=0 все команды C должны стать нулевыми.
4. Включить «Помощь при торможении», задержку2с. Одновременно вести A одним пальцем и удерживать «Тормоз заднего» другим. Отпустить тормоз. Увеличенный предел ретро должен следовать задержанному запросу, включая отпускание; выбор режима сам не означает постоянный полный ретро.
5. Удерживая ввод, свернуть вкладку/приложение. Вернуться: симуляция на паузе, зажатый ввод и команды C сброшены. Повторить при смене ориентации и отмене сенсорного жеста. После возобновления двигатель не должен включаться от старого удержания.
6. На Restart/паузе расцепить и снова сцепить AB; повторить BC. Другая связь остаётся. При движении расцепка немедленно отключает ассистент; повторный захват не включает его до явного выбора режима.
7. На паузе выбрать «Один тягач»: C/BC физически отсутствуют. Вернуть поезд. Проверить независимые размеры A/C и быстрые массы B/A10% и1000%; смена массы не должна сама менять тягу или k/c.
8. Открыть сцену «Торможение со смещением»40м/с, выполнить торможение. Экспортировать JSON и CSV, импортировать JSON в той же сборке и воспроизвести. Проверить таблицу сравнений, включая неудачные исходы, и открытие ссылки «Поделиться» как нового опыта на паузе.

При отказе сохранить JSON, снимок/видеозапись, шаг сценария, сообщения и SHA. Отдельно указать, что получилось фактически проверить. Закрывать Android-критерий по одному только успешному HTTP-ответу или эмуляции нельзя.
