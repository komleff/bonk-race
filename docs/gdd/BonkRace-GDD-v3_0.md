# Bonk Race — Game Design Document

**Версия:** 3.0
**Дата:** 06.03.2026
**Авторы:** Дмитрий Комлев, Claude Opus
**Статус:** Draft
**Базовый проект:** Slime Arena (физический движок, серверная инфраструктура)

---

## 1. Обзор

### 1.1 Краткое описание

Bonk Race — казуальная аркадная гонка на время (тайм-триал) с асинхронным соревнованием через «призраков». Игрок управляет круглым персонажем (блобом), проходя коридорные трассы с препятствиями за минимальное время. Ключевая механика — ньютоновская физика с инерцией, дрифтом и wall-thrust (ускорение при скольжении о стены).

### 1.2 Цели дизайна

- Перенести «прикольную» ньютоновскую физику Slime Arena в понятный и компактный гоночный формат.
- Создать петлю «ещё одна попытка» через мгновенный рестарт, ghost-соперника и трассу дня.
- Обеспечить честное соревнование: никаких gameplay-преимуществ за деньги или рекламу.
- Дать игроку ощущение прогресса даже при слабом времени: медали, косметика, стрики.

### 1.3 Целевая аудитория

- Казуальные игроки браузерных платформ (13–55+).
- Спидраннеры и любители лидербордов.
- Игроки Telegram Mini Apps, ищущие короткие соревновательные сессии.

### 1.4 Платформы

| Платформа | Приоритет | Особенности |
|-----------|-----------|-------------|
| Telegram Mini Apps | P0 | Основная точка роста. 500M пользователей Mini Apps. Telegram Stars, шеринг в чаты, рефералы. |
| CrazyGames | P0 | 35–40M MAU. Basic Launch 2 недели без монетизации. Лидерборд-API (ASC, недельный сброс). |
| Yandex Games | P1 | 30M MAU. 58% женщин, 38% старше 55. Крупный UI, русская локализация обязательна. |
| Standalone Web | P2 | Для тестирования и прямого трафика. |

### 1.5 Сеттинг и визуальный стиль

**Персонаж:** круглое существо (блоб/колобок) с выразительным лицом на боку (глаза, рот, брови на «экваторе» сферы). Лицо смотрит в направлении движения. При дрифте — выражение «испуга» (микроанимация). При wall-thrust — лицо «прижимается» к стене (комичный эффект).

**Камера:** строгий вид сверху (top-down), портретная ориентация. Камера плавно следует за блобом с лёгким опережением по вектору движения.

**Визуальная читаемость:** яркий контраст между безопасными зонами (синие/зелёные) и опасными (красные). Направление трассы всегда понятно. Каждые 3–5 секунд — визуальное решение (поворот, развилка, препятствие).

## 2. Core-loop (Основной игровой цикл)

```
┌─────────────────────────────────────────────────────┐
│  1. ГЛАВНОЕ МЕНЮ                                     │
│     Трасса дня → лидерборд → стрик                  │
│                    ↓                                 │
│  2. IDLE START                                       │
│     Блоб на старте. Ghost(ы) видны.                 │
│     Касание экрана = мгновенный старт.              │
│                    ↓                                 │
│  3. ЗАЕЗД                                            │
│     Физика, препятствия, монеты, wall-thrust.       │
│     Таймер тикает. Ghost рядом.                     │
│                    ↓                                 │
│  4a. ФИНИШ           4b. СМЕРТЬ                     │
│     Время, медаль,       Мгновенный рестарт         │
│     сравнение с ghost.   (<0.5 сек) → п.2           │
│           ↓                                          │
│  5. РЕЗУЛЬТАТЫ                                       │
│     Новый рекорд? Позиция в лидерборде.             │
│     Rewarded ad: x2 монет. Шеринг.                  │
│           ↓                                          │
│  6. МЕТА                                             │
│     Гача, Battle Pass, кастомизация.                │
│     → Назад к п.1 или п.2 (повтор)                 │
└─────────────────────────────────────────────────────┘
```

**Ключевые правила цикла:**

- Рестарт после смерти: мгновенный (<0.5 сек), без промежуточных экранов, без рекламы.
- Попытки: бесконечные, без системы энергии.
- Бонусы перед стартом: отсутствуют. Все игроки начинают в равных условиях.
- Реклама: только после успешного финиша (rewarded, опционально) или в меню (interstitial между сессиями).

## 3. Управление и физика

### 3.1 Управление (Drag-to-steer)

Блоб всегда ускоряется в направлении курсора/пальца. При отпускании — FlightAssist автоматически тормозит.

| Платформа | Ввод | Описание |
|-----------|------|----------|
| Десктоп | Мышь | Блоб ускоряется к позиции курсора. ЛКМ зажата = газ. Отпускание = автоторможение. |
| Мобильные | Виртуальный джойстик | Аналогично Slime Arena: адаптивный джойстик, направление = вектор тяги. |

### 3.2 Физика

Физика наследуется из Slime Arena без изменений. Все параметры задаются через конфигурацию трассы.

**Модель движения:** ньютоновская, force-based. Ускорения вычисляются как `a = F/m`.

**Интегратор:** Semi-Implicit Euler, фиксированный тик (30 Гц или 60 Гц — определяется при тестировании).

**Порядок систем:** FlightAssistSystem → PhysicsSystem → CollisionSystem.

**FlightAssist (всегда включён):**
- Поворот к целевому курсу (направление джойстика/мыши).
- Компенсация бокового дрейфа.
- Автоматическое торможение при отсутствии ввода.
- Мягкое гашение перескорости после столкновений.

### 3.3 Конфигурация физики по трассам (Engine Scaling)

Каждая трасса имеет собственный набор физических параметров. На обучающих трассах — слабый двигатель и высокое трение (минимум заносов). На продвинутых — полная мощность.

| Параметр | Тренировочная 1 | Тренировочная 5 | Трасса дня (норма) |
|----------|-----------------|-----------------|---------------------|
| `thrustForwardN` | 3000 | 6000 | 9000 |
| `thrustLateralN` | 3000 | 5500 | 8500 |
| `turnTorqueNm` | 80 | 130 | 175 |
| `linearDragK` | 0.25 | 0.15 | 0.10 |
| `comfortableBrakingTimeS` | 1.5 | 2.5 | 3.5 |

Точные значения подлежат балансировке при тестировании. Все параметры хранятся в `TrackConfig` и загружаются из конфига.

### 3.4 Wall-thrust

При скольжении боком о безопасную стену блоб получает микроускорение вдоль стены. Это вознаграждает рискованный стиль: опытные игроки намеренно «bonk'ают» стены для набора скорости.

**Формула:** `boostForce = wallThrustCoeff * normalForce * tangentDirection`

Параметр `wallThrustCoeff` задаётся в конфиге трассы. По умолчанию: 0.3.

### 3.5 Детерминизм и refresh rate

Физика рассчитывается с фиксированным timestep (`fixedDeltaTime = 1/tickRate`), независимо от частоты обновления экрана (60/120/144/165 Hz). Рендер интерполирует между физическими кадрами. Результат заезда идентичен при одинаковых input-ах на любом устройстве.

## 4. Левел-дизайн

### 4.1 Трасса дня

Единый контент для всех игроков. Обновляется раз в 24 часа (00:00 UTC). Все играют одну трассу — «эффект Wordle».

**Генерация:** из пула вручную созданных сегментов (пресетов) с фиксированным seed на основе даты. Seed = hash(дата). Сервер хранит конфигурацию трассы и раздаёт клиентам. Одинаковый seed = одинаковая трасса на всех устройствах.

**Структура трассы:** точка A (старт) → коридор с препятствиями → точка B (финиш). Не лабиринт с тупиками, а коридорная система с развилками. Основной путь всегда очевиден. Оптимальный путь — нетривиален и требует скилла.

**Ориентировочная длительность:** 30–90 секунд при оптимальном прохождении.

### 4.2 Элементы трасс

**Безопасные стены (Bonk-стены):**
- Цвет: синий/зелёный.
- При касании: упругий отскок с потерей скорости + wall-thrust при скольжении.
- Звуковой эффект: «bonk!» — фирменный звук игры.

**Опасные стены (смерть):**
- Цвет: красный, с визуальным предупреждением (шипы/свечение).
- При касании: мгновенное поражение → рестарт.

**Динамические препятствия:**
- Катящиеся объекты (шары) — предсказуемая траектория, нужно подгадать тайминг.
- Вращающиеся турели — фиксированная позиция, вращаются с постоянной скоростью.
- Выдвигающиеся блоки — ритмичное появление/исчезновение.

**Поверхности:**
- Замедляющая (слайм/грязь) — повышенное трение, `linearDragK` × 3.
- Ускоряющая (гладкая) — пониженное трение + мгновенный буст, `linearDragK` × 0.3.
- Ледяная — пониженное трение без буста, дрифт усиливается. `linearDragK` × 0.05.

**Pickup-бустеры (подбираются на трассе):**
- Нитро: мгновенный рывок вперёд. Одноразовый. Одинаковый для всех.
- Телепорт: перемещение на несколько секций вперёд (shortcut с риском, т.к. нужно знать, куда попадёшь).

Все pickup-бустеры расположены в одинаковых позициях для всех игроков и действуют в рамках текущего заезда.

### 4.3 Тренировочные трассы

5 фиксированных трасс с нарастающей сложностью. Не меняются. Доступны из меню параллельно с трассой дня (не блокируют основной контент).

| Трасса | Физика | Новая механика | Ghost-учитель |
|--------|--------|----------------|---------------|
| 1. «Прямая» | Слабый двигатель, высокое трение | Базовое управление, торможение | Да |
| 2. «Повороты» | Средний двигатель, среднее трение | Дрифт, повороты | Да |
| 3. «Стены» | Средний двигатель | Wall-thrust (bonk) | Да |
| 4. «Опасность» | Полный двигатель | Опасные стены, тайминг | Да |
| 5. «Всё вместе» | Полный двигатель | Динамические препятствия, pickup | Да |

Ghost-учитель на тренировочных трассах — полупрозрачный блоб, демонстрирующий оптимальную траекторию. Не соперник, а гайд.

Медали на тренировочных трассах дают стартовую косметику (первый скин, первый след).

При первом входе в игру — подсказка: «Попробуй тренировочные трассы, чтобы освоить управление».

## 5. Призраки (Ghosts) и рейтинги

### 5.1 Типы призраков

На трассе одновременно отображаются до 2 призраков:

| Призрак | Источник | Визуал |
|---------|----------|--------|
| Personal Best | Лучший результат игрока на текущей трассе | Полупрозрачный силуэт блоба игрока (его скин) |
| Соперник | Игрок на 1–3 позиции выше в лидерборде | Полупрозрачный силуэт с именем над ним |

Призраки не имеют коллизий. Они — визуальные ориентиры.

### 5.2 Подбор соперника

Сервер выбирает соперника из лидерборда по алгоритму:

1. Найти позицию текущего рекорда игрока.
2. Выбрать случайного игрока на 1–3 позиции выше.
3. Если игрок — новичок (нет рекорда) → показать ghost с медальным временем Bronze.

### 5.3 Ghost-как-учитель

На тренировочных трассах: предзаписанный ghost, демонстрирующий оптимальную траекторию.

Инсайт Data Wing: ghost автоматически обучает оптимальным маршрутам без текстовых подсказок. Игроки интуитивно следуют за ним.

### 5.4 Тирированные ghost-вызовы (post-launch)

После запуска — добавить систему: побей Bronze ghost → открой Silver → Gold → Author (время разработчика). Создаёт прогрессию внутри каждой трассы.

### 5.5 Формат данных ghost

Клиент записывает replay: массив `{ tick, posX, posY, angle }` с частотой tickRate.

Для 60-секундного заезда при 30 Hz: 1800 кадров × ~12 байт = ~21 КБ (сжатый). Хранится на сервере. Отдаётся клиенту при запросе трассы.

### 5.6 Лидерборд «Трасса дня»

- Единственный рейтинг: лучшее время прохождения текущей трассы дня.
- Сброс: каждые 24 часа вместе со сменой трассы.
- Отображение: топ-100 + позиция игрока (sticky-строка, если вне топ-100).
- Друзья-лидерборд: отдельная вкладка «Друзья» (Telegram-контакты, CrazyGames-друзья).

**CrazyGames Leaderboard API:**
- Ограничение: 1 лидерборд на игру (MVP платформы).
- Решение: CrazyGames-лидерборд = «лучшее время за неделю» (scoreSorting: ASC, metricType: MINUTES, сброс Monday 7:00 UTC). Внутриигровой лидерборд = «трасса дня» (собственный бэкенд).

## 6. Медальная система

Каждая трасса (включая тренировочные) имеет 4 медальных времени:

| Медаль | Время | Описание |
|--------|-------|----------|
| Bronze | Верхние 80% финишировавших | «Ты прошёл» |
| Silver | Верхние 40% | «Хорошо» |
| Gold | Верхние 10% | «Отлично» |
| Author | Лучшее время разработчика | «Мастер» |

Для трассы дня: медальные пороги рассчитываются динамически сервером на основе распределения результатов первых N финишей (N = 100–500). До накопления данных — фиксированные пороги из конфига трассы.

Для тренировочных трасс: фиксированные пороги в конфиге.

Получение медали — награда монетами + XP Battle Pass.

## 7. Экономика и монетизация

### 7.1 Принцип

Абсолютное равенство характеристик. Исход гонки определяется только скиллом. Никаких gameplay-преимуществ за деньги, рекламу или валюту.

### 7.2 Валюта

**Монеты (soft-валюта):**
- Источники: сбор на трассе (5–15 за заезд), медали (Bronze 10, Silver 25, Gold 50, Author 100), стрик-бонусы, rewarded ads (50 монет, кулдаун 1 час).
- Трата: гача-автомат (100 монет за спин).

### 7.3 Косметическая гача

Прямых покупок скинов нет. Все косметические предметы — из гача-автомата.

**Содержимое:**

| Категория | Примеры | Читаемость в top-down |
|-----------|---------|------------------------|
| Цвет/паттерн тела | Полоски, горох, градиент, космос, камуфляж | Высокая — верхняя полусфера |
| Шапка/аксессуар | Корона, бантик, пропеллер, рога, ушки, нимб | Высокая — торчит из силуэта |
| Лицо/выражение | Разные глаза, рты, брови | Низкая в gameplay, высокая в лидерборде/шеринге |
| След | Искры, пламя, радуга, пиксели, звёзды, сердечки | Очень высокая — основной видимый слой |
| Анимация финиша | Конфетти, фейерверк, взрыв звёзд | Видно при каждом финише |
| Контур/свечение | Неон, золото, радужный переход | Средняя — усиливает силуэт |
| Аватарка лидерборда | Рамки, фоны | Видно в лидерборде и шеринге |

**Pity-система:** гарантированный редкий предмет каждые 10 спинов.

**Дубликаты:** конвертируются в «пыль». Пыль = крафт конкретного предмета (50 пыли = 1 выбранный предмет редкости Common, 150 = Rare, 500 = Epic).

### 7.4 Battle Pass (сезон 4–6 недель)

**Бесплатный тир (40 уровней):** монеты, пыль, базовые скины, 1–2 средних скина.

**Премиум тир ($2–5 / Telegram Stars):** эксклюзивные скины, уникальный след, рамка аватарки, бонус x1.5 к монетам на трассе (экономический, не gameplay-бонус).

Самоокупаемый: завершение пасса даёт достаточно валюты на покупку следующего.

Прогрессия: XP за финиши, медали, ежедневные задания, стрики.

### 7.5 Rewarded Video Ads

Основной источник дохода. Точки показа (все опциональные):

| Точка | Момент | Награда |
|-------|--------|---------|
| Удвоение монет | После успешного финиша | Монеты × 2 |
| Бонусный спин | В меню гачи | +1 спин гачи |
| Монеты из воздуха | В меню (кулдаун 1 час) | 50 монет |

Кнопка rewarded ad **не появляется** на экране гонки — требование CrazyGames.

Реклама показывается только в позитивные моменты (после рекорда, после финиша) — модель Crossy Road.

### 7.6 Прямые покупки (малый объём)

| Товар | Цена | Описание |
|-------|------|----------|
| Отключение interstitial-рекламы | $2.99–$4.99 | Единоразово, навсегда |
| Стартер-пак | $1.99 | Скин + 500 монет + рамка (один раз) |
| Battle Pass (премиум) | $2–5 | На сезон |

### 7.7 Telegram Stars

Для Telegram Mini Apps: все прямые покупки через Stars. Stars конвертируются в монеты или премиум-контент.

### 7.8 Чего нет

- Энергии / ограничения попыток.
- Бонусов перед стартом.
- Ускорения прогрессии за деньги.
- Покупки бустеров за реальные деньги.
- VIP-статуса с gameplay-преимуществами.
- Прокачки, влияющей на физику/характеристики блоба.

## 8. Стрики и ежедневная мотивация

**Стрик:** последовательные дни с хотя бы одним финишем на трассе дня.

| День стрика | Награда |
|-------------|---------|
| 1 | 20 монет |
| 3 | 50 монет |
| 7 | 100 монет + редкая рамка |
| 14 | 200 монет |
| 30 | 500 монет + эпическая рамка |

**Заморозка:** 1 день заморозки бесплатно (не теряешь стрик за 1 пропущенный день). Дополнительные заморозки — за 50 монет.

Стрик-индикатор отображается на главном экране.

## 9. Виральность и социальные механики

### 9.1 1v1 Ghost Sharing (Telegram)

Кнопка «Вызов» после финиша генерирует ссылку: «Я прошёл Трассу дня за 0:24.58! Побей моего призрака → [ссылка]».

При переходе по ссылке: игра загружается с ghost отправителя. Результат: соревнование 1v1 через Telegram-чаты.

### 9.2 Wordle-эффект

Шеринг результатов в формате emoji-сетки:

```
🏁 Bonk Race — Трасса #127
⏱ 0:34.21 🥇 Gold
💀💀💀✅
🔥 7-дневный стрик
```

Компактно, визуально, провоцирует обсуждение.

### 9.3 Рефералы (Telegram)

Пригласи друга → оба получают 100 монет + уникальную рамку «Дружба». Реферальная ссылка генерируется в меню.

### 9.4 Ghost носит скин

Ghost-соперник отображается с косметикой владельца (скин, след, шапка). Другие игроки видят, во что ты одет → мотивация к покупке косметики.

## 10. Архитектура

### 10.1 Принцип: клиент считает, сервер валидирует

Для одиночного тайм-триала серверная симуляция в реальном времени избыточна. Клиент рассчитывает физику локально. У игрока нет лагов, интерполяции, проблем с задержками.

### 10.2 Поток данных

```
┌──────────────────────────────────────────────────────────┐
│                       КЛИЕНТ                              │
│  1. Загрузка: GET /api/track-of-day → TrackConfig         │
│  2. Загрузка: GET /api/ghosts?trackId=X → Ghost[]         │
│  3. Локальная симуляция: PhysicsSystem (fixedDeltaTime)    │
│  4. Запись replay: InputReplay { tick, input }[]           │
│  5. Финиш: POST /api/submit-run → { time, replay, hash }  │
└───────────────────────────┬──────────────────────────────┘
                            │ HTTPS
                            ▼
┌──────────────────────────────────────────────────────────┐
│                       СЕРВЕР                              │
│  1. Приём результата + replay                             │
│  2. Базовая валидация: time > теоретический минимум,       │
│     чекпоинты в правильном порядке                        │
│  3. Запись в лидерборд (если новый рекорд)                │
│  4. Хранение replay для ghost                             │
│  5. Асинхронная пересимуляция (для топ-N лидерборда)      │
└──────────────────────────────────────────────────────────┘
```

### 10.3 Уровни валидации

| Уровень | Что проверяется | Когда |
|---------|-----------------|-------|
| 1 — Базовый | `time > minTheoreticalTime`, чекпоинты, формат данных | Каждый заезд |
| 2 — Replay | Сервер проигрывает replay на копии движка, сравнивает время | Топ-100 лидерборда |
| 3 — Выборочный | Случайная выборка + подозрительные результаты | Фоновый процесс |

### 10.4 Технический стек

Наследуется из Slime Arena:

| Компонент | Технология |
|-----------|------------|
| Клиент | TypeScript + Preact (UI) + Canvas (рендер) |
| Сервер | TypeScript + Node.js |
| Физика (shared) | Shared-модуль: PhysicsSystem, CollisionSystem, FlightAssistSystem |
| База данных | PostgreSQL (профили, лидерборды, replay) |
| Кэш | Redis (сессии, конфиги трасс) |
| Платформы | Telegram Bot API, CrazyGames SDK, Yandex Games SDK |

### 10.5 Фиксированный timestep на клиенте

Физика обновляется с `fixedDeltaTime` (1/30 или 1/60 сек) в accumulator-цикле. Рендер интерполирует между кадрами. Результаты идентичны на 60/120/144/165 Hz мониторах.

## 11. Требования к UI

### 11.1 Визуальная читаемость

- Безопасные стены: синие/зелёные, мягкие формы.
- Опасные стены: красные, с шипами/свечением.
- Pickup-бустеры: жёлтые, с анимацией пульсации.
- Монеты: золотые звёздочки, с sparkle-эффектом.
- Ghost: полупрозрачный (40%), с именем над ним.
- Personal Best ghost: полупрозрачный (30%), без имени.

### 11.2 HUD (минимальный)

- Таймер (крупный, сверху по центру).
- Текущая / лучшая разница времени с ghost (± сек, зелёный/красный).
- Счётчик монет (мелкий, угол).

### 11.3 Адаптация под Yandex Games

- Крупные кнопки (минимум 48×48 dp).
- Увеличенный шрифт в меню.
- Полная русская локализация.
- Нет мелкого текста в HUD.

## 12. Roadmap

### MVP (4–6 недель)

- Физика (shared-модуль из Slime Arena).
- Управление (drag-to-steer, мышь + тач).
- 1 трасса-эталон (ручная, не генерируемая).
- 1 тренировочная трасса.
- Мгновенный рестарт.
- Personal best ghost.
- Базовый лидерборд (внутриигровой).
- Минимальный UI (таймер, рестарт, лидерборд).
- Деплой на Telegram Mini Apps + standalone web.

**Цель MVP:** проверить гипотезу «ньютоновская физика + тайм-триал + ghost = retention без монетизации».

### Post-MVP Sprint 1 (2–4 недели)

- Трасса дня (seeded generation из пресетов).
- Ghost соперника (подбор по скиллу).
- Медальная система.
- CrazyGames интеграция (SDK, лидерборд).
- Interstitial ads (между сессиями).

### Post-MVP Sprint 2 (2–4 недели)

- Косметическая система (скины, шапки, следы).
- Гача-автомат.
- Rewarded ads.
- 5 тренировочных трасс с engine scaling.
- Стрик-система.
- 1v1 ghost sharing для Telegram.

### Post-MVP Sprint 3 (2–4 недели)

- Battle Pass (сезон 1).
- Yandex Games интеграция.
- Прямые покупки + Telegram Stars.
- Wordle-эффект шеринг.
- Рефералы.

### Дальнейшее развитие

- Серверная replay-валидация (уровень 2).
- Тирированные ghost-вызовы (Bronze/Silver/Gold/Author ghost).
- Друзья-лидерборд.
- Редактор трасс (комьюнити-контент).
- Сезонные серии косметики (Космос, Хэллоуин, Японская кухня, Сладости).
- Score-attack режим (1 минута, сбор максимума) — если тайм-триал «душит казуалов».
