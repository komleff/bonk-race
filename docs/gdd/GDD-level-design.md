## 4. Дизайн трасс

### 4.1 Трасса дня

Единый контент для всех игроков. Обновляется раз в 24 часа (00:00 UTC). Все играют одну трассу — «эффект единой трассы».

**Генерация:** из пула вручную созданных сегментов (пресетов) с фиксированным зерном генерации на основе даты. Зерно генерации = hash(дата). Сервер хранит конфигурацию трассы и раздаёт клиентам. Одинаковое зерно генерации = одинаковая трасса на всех устройствах.

**Структура трассы:** точка A (старт) → коридор с препятствиями → точка B (финиш). Не лабиринт с тупиками, а коридорная система с развилками. Основной путь всегда очевиден. Оптимальный путь — нетривиален и требует мастерства.

**Ориентировочная длительность:** 30–90 секунд при оптимальном прохождении.

### 4.2 Элементы трасс

**Безопасные стены (Bonk-стены):**

- Цвет: синий/зелёный.
- При касании: упругий отскок с потерей скорости + wall-thrust при скольжении.
- Звуковой эффект: «bonk!» — фирменный звук игры.

**Опасные стены (смерть):**

- Цвет: красный, с визуальным предупреждением (шипы/свечение).
- При касании: мгновенное поражение → рестарт.

**Динамические препятствия:**

- Катящиеся объекты (шары) — предсказуемая траектория, нужно подгадать тайминг.
- Вращающиеся турели — фиксированная позиция, вращаются с постоянной скоростью.
- Выдвигающиеся блоки — ритмичное появление/исчезновение.

**Поверхности:**

- Замедляющая — повышенное трение (втрое выше базового). Визуал: липкая поверхность.
- Ускоряющая — пониженное трение и мгновенный буст скорости. Визуал: гладкая поверхность.
- Ледяная — практически отсутствует трение, дрифт усиливается. Буста нет.

**Pickup-бустеры (подбираются на трассе):**

- Нитро: мгновенный рывок вперёд. Одноразовый. Одинаковый для всех.
- Телепорт: перемещение на несколько секций вперёд (обходной путь с риском, т.к. нужно знать, куда попадёшь).

Все pickup-бустеры расположены в одинаковых позициях для всех игроков и действуют в рамках текущего заезда.

### 4.3 Тренировочные трассы

5 фиксированных трасс с нарастающей сложностью. Не меняются. Доступны из меню параллельно с трассой дня (не блокируют основной контент).

| Трасса | Физика | Новая механика | Призрак-учитель |
|--------|--------|----------------|---------------|
| 1. «Прямая» | Слабый двигатель, высокое трение | Базовое управление, торможение | Да |
| 2. «Повороты» | Средний двигатель, среднее трение | Дрифт, повороты | Да |
| 3. «Стены» | Средний двигатель | Wall-thrust (bonk) | Да |
| 4. «Опасность» | Полный двигатель | Опасные стены, тайминг | Да |
| 5. «Всё вместе» | Полный двигатель | Динамические препятствия, pickup | Да |

Призрак-учитель на тренировочных трассах — полупрозрачный блоб, демонстрирующий оптимальную траекторию. Не соперник, а проводник.

Медали на тренировочных трассах дают стартовую косметику (первый скин, первый след).

При первом запуске игрок сразу попадает на простейшую тренировочную трассу без меню и кнопок. Главное меню и трасса дня открываются после первого успешного финиша.
