## 15. Пользовательские карты (User-Generated Content)

### 15.1 Обоснование

**Проблема:** текущий контент-план (трасса дня + 5 тренировочных) создаёт потолок replayability. После освоения тренировочных трасс единственный повод возвращаться — daily track. Это ограничивает D7+ retention.

**Решение:** дать игрокам инструмент для создания собственных трасс и делиться ими с другими.

**Конкурентный анализ:**

| Игра | UGC-механика | Результат |
|------|-------------|-----------|
| Geometry Dash | Полноценный редактор уровней | 95%+ контента = UGC, игра живёт 10+ лет, 150M+ загрузок |
| Trackmania | Редактор трасс + обмен | Эталон жанра, комьюнити создало 500K+ трасс |
| Super Mario Maker 1+2 | Создание + рейтинг уровней | 8M+ продаж, UGC = основная ценность |
| Happy Wheels | Редактор + шаринг | Стал вирусным именно благодаря UGC и стримерам |
| GD Dash / Stumble Guys | Нет UGC | Контент-зависимость от разработчиков, быстрое выгорание |

**Вывод:** в жанре «skill-based obstacle racing» UGC — проверенный killer feature. Geometry Dash — прямой аналог, где UGC буквально сделал игру.

### 15.2 Прогноз пользы

| Метрика | Ожидаемый эффект | Обоснование |
|---------|-----------------|-------------|
| D7 Retention | +15–25% | Возврат к своим картам + постоянный поток нового контента от комьюнити |
| Session Length | +30–50% | Создание карт = отдельный игровой цикл, не пересекающийся с гонками |
| Виральность | Значительный рост | Органический шаринг «пройди мою карту» через Telegram-чаты |
| LTV | Рост за счёт retention | Больше дней в игре → больше ad impressions и покупок |
| Стримеры | Новый контент-слой | «Самые сложные карты», «тролл-карты», speedrun WR — готовые форматы для YouTube/TikTok |
| Контент-затраты | Снижение | Бесконечный контент без затрат на продакшн |

### 15.3 Редактор трасс

**Принципы:**

- Casual-friendly: drag & drop на сетке, минимум параметров, максимум интуитивности.
- Мгновенный тест: кнопка «Играть» прямо в редакторе для проверки трассы.
- Обязательный clear check: автор должен пройти карту от старта до финиша перед публикацией (как в Super Mario Maker).

**Доступные элементы:**

| Категория | Элементы |
|-----------|----------|
| Структура | Старт, финиш, чекпоинты |
| Стены | Безопасные (bonk-стены), опасные (смерть) |
| Поверхности | Замедляющая (слайм), ускоряющая (гладкая), ледяная |
| Pickup-бустеры | Нитро, телепорт |
| Динамические препятствия | Катящиеся шары, вращающиеся турели, выдвигающиеся блоки |

**Ограничения:**

- Минимальная длина трассы: 15 секунд оптимального прохождения.
- Максимальная длина: 120 секунд оптимального прохождения.
- Максимальное количество элементов: определяется тестированием производительности (см. Приложение A).
- Обязательно: 1 старт, 1 финиш, минимум 1 чекпоинт.

### 15.4 Публикация и каталог

**Разделы каталога:**

| Раздел | Логика попадания |
|--------|-----------------|
| Свежие | Все опубликованные карты, сортировка по дате |
| Популярные | Топ по лайкам × прохождениям за последние 7 дней |
| Рекомендуемые | Ручной отбор модераторами из «Популярных» |

**Community Track of the Day:**

- Ежедневно выбирается лучшая пользовательская карта из «Рекомендуемых».
- Отображается на главном экране рядом с официальной трассой дня.
- Собственный лидерборд и медали.
- Автор получает уведомление и награду (монеты + уникальный титул).

**Рейтинг карт:**

- Лайки (палец вверх после прохождения).
- Количество прохождений.
- Средний рейтинг (1–5 звёзд, опционально после финиша).
- Процент финиша (показатель сложности).

**Рейтинг авторов:**

- Суммарные лайки всех карт.
- Количество карт в «Рекомендуемых».
- Количество попаданий в Community Track of the Day.

### 15.5 Модерация

| Уровень | Механизм | Описание |
|---------|----------|----------|
| Автоматический | Clear check | Автор обязан пройти карту — исключает непроходимые трассы |
| Автоматический | Паттерн-фильтр | Детекция оскорбительных фигур/текстов из стен |
| Пользовательский | Жалобы | Кнопка «Пожаловаться» на странице карты |
| Ручной | Модерация «Рекомендуемых» | Только проверенные карты попадают в витрину и Community TotD |

Карты с N+ жалоб автоматически скрываются до ручной проверки.

### 15.6 Социальные механики UGC

- **Шаринг карты:** ссылка в Telegram → друг открывает игру с этой картой.
- **Ghost-рекорды:** полноценная ghost-система на пользовательских картах (Personal Best + соперник).
- **Лидерборды per-карта:** топ-100 + позиция игрока для каждой пользовательской карты.
- **Челленджи:** автор ставит рекорд → друзья пытаются побить через shared link.

**Награды для топ-авторов:**

| Достижение | Награда |
|-----------|---------|
| 10 опубликованных карт | Рамка «Картограф» |
| 1000 суммарных прохождений | След «Творец» |
| 1 карта в Community TotD | Титул «Дизайнер дня» |
| 10 карт в «Рекомендуемых» | Эпическая рамка «Мастер-Картограф» |

### 15.7 Монетизация UGC

**Принцип:** все gameplay-элементы редактора доступны бесплатно. Монетизация — только через косметику и удобство.

- **Премиум-элементы редактора:** декоративные текстуры стен, уникальные фоны трасс, визуальные эффекты (снег, дождь, неон). Доступны через Battle Pass или за монеты.
- **Слоты публикации:** 3 карты бесплатно, дополнительные слоты — 200 монет каждый.
- **Battle Pass интеграция:** эксклюзивные элементы редактора в премиум-тире.

### 15.8 Техническая реализация

**Формат карты:** JSON-конфиг, аналогичный `TrackConfig` для официальных трасс.

```json
{
  "version": 1,
  "authorId": "user_123",
  "title": "Ледяной ад",
  "elements": [
    { "type": "start", "x": 100, "y": 50 },
    { "type": "finish", "x": 100, "y": 9500 },
    { "type": "wall_safe", "points": [...] },
    { "type": "zone_ice", "rect": { "x": 200, "y": 3000, "w": 400, "h": 600 } },
    { "type": "obstacle_turret", "x": 300, "y": 5000, "rpm": 10 }
  ],
  "checkpoints": [{ "y": 3000 }, { "y": 6000 }],
  "authorTime": 42.15
}
```

**Размер:** ~5–50 КБ JSON (зависит от количества элементов).

**API:**

| Эндпоинт | Метод | Описание |
|----------|-------|----------|
| `/api/ugc/tracks` | POST | Публикация карты (с clear check) |
| `/api/ugc/tracks` | GET | Каталог (фильтры: свежие, популярные, рекомендуемые) |
| `/api/ugc/tracks/:id` | GET | Загрузка конкретной карты |
| `/api/ugc/tracks/:id/rate` | POST | Лайк / рейтинг |
| `/api/ugc/tracks/:id/report` | POST | Жалоба |
| `/api/ugc/ghosts` | GET/POST | Ghost-система (аналогично официальным трассам) |

**Хранение:** PostgreSQL (метаданные, рейтинги, авторы) + S3/CDN (JSON-конфиги карт).

**Совместимость с существующей архитектурой:**

- Детерминированная физика → карты работают одинаково у всех.
- Ghost-система → рекорды и соревнования на UGC-картах из коробки.
- Replay-валидация → античит на пользовательских картах без доработок.
- Медальная система → автоматический расчёт порогов по распределению результатов.
