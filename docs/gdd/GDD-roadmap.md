## 12. План развития

### MVP (4–6 недель)

- Физика (разделяемый модуль из Slime Arena).
- Управление (перетаскивание для поворота, мышь + тач).
- 1 трасса-эталон (ручная, не генерируемая).
- 1 тренировочная трасса.
- Мгновенный рестарт.
- Призрак личного рекорда.
- Базовая таблица лидеров (внутриигровая).
- Минимальный интерфейс (таймер, рестарт, таблица лидеров).
- Деплой на Telegram Mini Apps + автономный веб.

**Цель MVP:** проверить гипотезу «ньютоновская физика + заезд на время + призрак = удержание без монетизации».

### Спринт 1 (2–4 недели)

- Трасса дня (генерация из начального числа на основе заготовок).
- Призрак соперника (подбор по уровню мастерства).
- Медальная система.
- CrazyGames интеграция (SDK, таблица лидеров).
- Межсессионная реклама (между заездами).

### Спринт 2 (2–4 недели)

- Косметическая система (скины, шапки, следы).
- Гача-автомат.
- Реклама с вознаграждением.
- 5 тренировочных трасс с масштабированием сложности.
- Стрик-система.
- Обмен призраками один на один для Telegram.

### Спринт 3 (2–4 недели)

- Боевой пропуск (сезон 1).
- Yandex Games интеграция.
- Прямые покупки + Telegram Stars.
- Виральный шеринг результатов.
- Рефералы.

**Этапные ворота:** спринты 4–5 начинаются только после: (1) заморозки физического движка, (2) стабильной генерации трассы дня, (3) подтверждённого удержания на 7-й день > 10%.

### Спринт 4 — Пользовательский контент: упрощённая версия (3–5 недель)

Шаблонный редактор (перетаскивание, базовые элементы), проверка проходимости, приватный обмен картами через ссылки в Telegram, система жалоб.

### Спринт 5 — Пользовательский контент: полная версия (2–4 недели)

Публичный каталог (Свежие, Популярные, Рекомендуемые), лучшая карта сообщества дня, рейтинг авторов, титулы и косметика для авторов, динамические препятствия в редакторе, премиум-элементы редактора в боевом пропуске.

### Дальнейшее развитие

- Серверная валидация через пересимуляцию (уровень 2).
- Ступенчатые призраки-вызовы (Бронза/Серебро/Золото/Автор).
- Таблица лидеров среди друзей.
- Сезонные серии косметики (Космос, Хэллоуин, Японская кухня, Сладости).
- Режим на счёт (1 минута, сбор максимума) — если заезд на время «душит казуалов».
- Маркеры смерти — кастомные метки на трассе в местах гибели игроков (видны другим участникам). Социальный и комедийный элемент, стимулирует покупку косметики.

## 13. Ключевые метрики

| Метрика | Цель | Источник |
| --------- | ------ | ---------- |
| Удержание 1-й день | > 30% | Базовая для CrazyGames Basic Launch |
| Удержание 7-й день | > 10% | Стрики, трасса дня |
| Средняя длительность сессии | > 5 мин | Петля «ещё одна попытка» |
| Перезапуски за сессию | > 10 | Мгновенный рестарт работает |
| % финишировавших (первая попытка) | 30–50% | Баланс сложности |
| Просмотры рекламы с вознаграждением | > 15% | Монетизация здорова |
| Принятие вызова призрака | > 20% из шеринга | Виральность работает |
| Пользовательский контент: карт создано / ежедневных активных игроков | > 1% | Здоровая экосистема контента |
| Пользовательский контент: % карт с >10 прохождениями | > 30% | Качество каталога |
