## 12. Roadmap

### MVP (4–6 недель)

- Физика (shared-модуль из Slime Arena).
- Управление (drag-to-steer, мышь + тач).
- 1 трасса-эталон (ручная, не генерируемая).
- 1 тренировочная трасса.
- Мгновенный рестарт.
- Personal best ghost.
- Базовый лидерборд (внутриигровой).
- Минимальный UI (таймер, рестарт, лидерборд).
- Деплой на Telegram Mini Apps + standalone web.

**Цель MVP:** проверить гипотезу «ньютоновская физика + тайм-триал + ghost = retention без монетизации».

### Post-MVP Sprint 1 (2–4 недели)

- Трасса дня (seeded generation из пресетов).
- Ghost соперника (подбор по скиллу).
- Медальная система.
- CrazyGames интеграция (SDK, лидерборд).
- Interstitial ads (между сессиями).

### Post-MVP Sprint 2 (2–4 недели)

- Косметическая система (скины, шапки, следы).
- Гача-автомат.
- Rewarded ads.
- 5 тренировочных трасс с engine scaling.
- Стрик-система.
- 1v1 ghost sharing для Telegram.

### Post-MVP Sprint 3 (2–4 недели)

- Battle Pass (сезон 1).
- Yandex Games интеграция.
- Прямые покупки + Telegram Stars.
- Wordle-эффект шеринг.
- Рефералы.

### Post-MVP Sprint 4 — UGC Phase 1 (3–5 недель)

- Редактор трасс (drag & drop, все базовые элементы).
- Clear check (автор обязан пройти перед публикацией).
- Публикация карт и каталог («Свежие», «Популярные»).
- Рейтинг карт (лайки, прохождения).
- Ghost-система и лидерборды на пользовательских картах.
- Шаринг карты ссылкой в Telegram.
- Система жалоб и автомодерация.

### Post-MVP Sprint 5 — UGC Phase 2 (2–4 недели)

- Community Track of the Day.
- Раздел «Рекомендуемые» (ручная модерация).
- Рейтинг авторов.
- Титулы и косметика для топ-авторов.
- Премиум-элементы редактора (декоративные текстуры, фоны).
- Динамические препятствия в редакторе (турели, блоки).
- Интеграция UGC-элементов в Battle Pass.

### Дальнейшее развитие

- Серверная replay-валидация (уровень 2).
- Тирированные ghost-вызовы (Bronze/Silver/Gold/Author ghost).
- Друзья-лидерборд.
- Сезонные серии косметики (Космос, Хэллоуин, Японская кухня, Сладости).
- Score-attack режим (1 минута, сбор максимума) — если тайм-триал «душит казуалов».

## 13. Ключевые метрики

| Метрика | Цель | Источник |
|---------|------|----------|
| D1 Retention | > 30% | Базовая для CrazyGames Basic Launch |
| D7 Retention | > 10% | Стрики, трасса дня |
| Avg. Session Length | > 5 мин | Петля «ещё одна попытка» |
| Restarts per Session | > 10 | Мгновенный рестарт работает |
| % финишировавших (первая попытка) | 30–50% | Баланс сложности |
| Rewarded ad view rate | > 15% | Монетизация здорова |
| Ghost challenge acceptance | > 20% из шеринга | Виральность работает |
| UGC: карт создано / DAU | > 1% | Здоровая UGC-экосистема |
| UGC: % карт с >10 прохождениями | > 30% | Качество каталога |

## Приложение B. Источники решений

| Решение | Источник |
|---------|----------|
| Физика Slime Arena без изменений | Встреча 06.03: «физика остаётся та же самая» |
| Асинхронный PvP вместо real-time | Встреча 06.03: «на старте лучше без PvP» |
| Клиент считает, сервер валидирует | Обсуждение: проблемы с 400 ботами, latency |
| Без энергии, без бонусов перед стартом | Обсуждение: равные условия, не ломать core-loop |
| Drag-to-steer + ньютоновская физика | Текущее управление Slime Arena (тестировал Евгений) |
| Wall-thrust | Конкурентный анализ: Data Wing, предложение Gemini v2.0 |
| Engine scaling по трассам | Обсуждение: конфиг физики трассы, Data Wing onboarding |
| Медальная система | Конкурентный анализ: TrackMania, PolyTrack, Hot Lap League |
| Стрики с заморозкой | Конкурентный анализ: Duolingo, Wordle |
| Ghost по скиллу | Конкурентный анализ: Hot Lap League |
| Модель Crossy Road (rewarded ads) | Конкурентный анализ: 70%+ дохода от rewarded video |
| Требования CrazyGames | Анализ GPT: Basic Launch, refresh rate, ads policy |
| Круглые блобы с лицом на боку | Обсуждение: еда не работает в top-down, слайм — не бренд |
| UGC-система | Конкурентный анализ: Geometry Dash (10+ лет на UGC), Trackmania (500K+ трасс), Mario Maker (8M+ продаж) |
| Clear check (автовалидация проходимости) | Super Mario Maker «clear check» — автор обязан пройти уровень перед публикацией |
