# BonkLab — Руководство пользователя

## Что это такое

BonkLab — **инструмент для настройки физики движения** персонажа в Bonk Race. Это отдельная страница-песочница, где можно в реальном времени менять параметры двигателей, торможения, поворотов и среды, наблюдая результат сразу на экране.

**BonkLab — это НЕ игра.** Это dev-инструмент. Здесь нет других игроков, очков, монет или боевых механик. Только один персонаж и тестовая трасса.

---

## Для кого

- **Геймдизайнеры** — подбор ощущений от управления (отзывчивость, инерция, скольжение)
- **Разработчики** — диагностика физических багов, проверка формул
- **AI-ревьюеры** — понимание контекста при анализе кода в `client/src/lab/` и `shared/src/physics/`

---

## Как запустить

```bash
npm run dev:client    # http://localhost:5173/lab
```

Или собрать для передачи коллегам:

```bash
npm run build:lab --workspace=client    # → client/dist-lab/
```

## Интерфейс

### Игровое поле (основная часть экрана)

Персонаж (круг) управляется мышью. Куда ведёте курсор — туда «толкают двигатели». На персонаже видны три стрелки:

| Стрелка | Цвет | Что показывает |
|---------|------|----------------|
| Ускорение (FA) | Зелёная | Куда толкают двигатели прямо сейчас |
| Скорость | Голубая | Куда фактически летит персонаж |
| Коррекция | Оранжевая (пунктир) | Сколько силы тратится на компенсацию бокового сноса |

Жёлтый круг — маяк-цель (куда указывает ваш ввод).

### Камера

Персонаж находится в нижней части экрана (65% от верха), что обеспечивает лучший обзор вперёд по ходу движения.

### Тулбар (верхняя полоса)

| Кнопка | Что делает |
|--------|------------|
| **Restart** | Возвращает персонаж на старт с обратным отсчётом «Go!». Сбрасывает и запускает секундомер. |
| **Seed** | Число + кнопка «Rnd». Меняет расположение препятствий. Одинаковый seed = одинаковая трасса. |
| **Плотность** | Ползунок 0.1–25.0, по умолчанию 5.0. Больше = больше препятствий на карте. |
| **Сброс** | Возвращает ВСЕ параметры к исходным значениям из конфига. |
| **Экспорт** | Открывает окно с JSON всех параметров. Кнопка «Копировать» → буфер обмена. |
| **Импорт** | Открывает окно для вставки JSON. Параметры применяются мгновенно. |
| **Пресеты** | Готовые наборы параметров: Ультралёгкий, Slime Arena, Лёгкий и быстрый, Тяжёлый и инертный, Минимальный FA, Космос. Отображает имя активного пресета; при ручном изменении параметров переключается на «Custom». |

### Панель параметров (справа)

~45 параметров, сгруппированных по разделам. Каждый параметр — ползунок + числовое поле. Изменения применяются мгновенно.

**Группы:**

1. **Геометрия и масса** — масса персонажа, базовый радиус, коэффициент инерции
2. **Геометрия трассы** — pillarRadius, spikeRadius, passageRadius, passageGap
3. **Тяга** — сила двигателей (вперёд, назад, вбок, поворот)
4. **Лимиты скорости** — максимальные скорости (вперёд, назад, вбок, вращение)
5. **FA: Линейное** — время разгона/торможения, пороги, доля тяги автоторможения
6. **FA: Угловое** — усиление поворота, мёртвые зоны, время реакции
7. **FA: Задний ход** — *заблокирован* (новая механика, ещё не реализована в движке)
8. **FA: Компенсация дрейфа** — вкл/выкл, порог угла, время коррекции
9. **FA: Демпфирование** — гашение превышения скорости, осцилляций
10. **Окружение** — сопротивление воздуха, упругость стен, размеры карты, упругость проходов
11. **Зоны** — параметры зон (лёд, грязь, турбо). Грязь увеличивает трение и снижает скорость. Турбо ускоряет в направлении движения.
12. **Орбы** — count, density, minRadius, maxRadius, minSpeed, maxSpeed, spikeKill
13. **Масштабирование по массе** — экспоненты масштабирования сил при изменении массы

### HUD-телеметрия (верхний левый угол)

9 строк числовых показателей в реальном времени: скорость, угловая скорость, масса, рассогласование, состояние FA, текущая зона, время, дистанция, прогресс.

### Минимап (правый нижний угол)

Миниатюрная карта с точками препятствий, зон, старта/финиша, голубыми точками орбов и текущей позицией. Прямоугольник области обзора отражает смещение камеры.

## Типовые сценарии

### «Хочу сделать управление отзывчивее»

1. Увеличьте `Маршевый (вперёд)` в секции «Тяга»
2. Уменьшите `Время разгона` в секции «FA: Линейное»
3. Увеличьте `Усиление поворота` в секции «FA: Угловое»
4. Прокатитесь по трассе, оцените ощущения
5. Экспортируйте JSON и передайте разработчикам

### «Хочу больше скольжения / дрифта»

1. Выключите `Компенсация дрейфа` (toggle в секции «FA: Компенсация»)
2. Уменьшите `Линейное сопротивление` в секции «Окружение»
3. Или выберите пресет «Космос» (нулевое трение, полный отскок)

### «Хочу сравнить две конфигурации по времени прохождения»

1. Установите одинаковый Seed
2. Настройте первый вариант, нажмите Restart, пройдите трассу до клетчатой полосы финиша — на экране финиша отобразится итоговое время
3. Экспортируйте JSON (сохраните)
4. Настройте второй вариант, Restart, пройдите до финиша
5. Сравните время на экранах финиша и ощущения

### «Хочу передать настройки коллеге»

1. Экспорт → Копировать
2. Отправить JSON коллеге (Slack, email, etc.)
3. Коллега: Импорт → Вставить → Применить

## Что означают стрелки

Когда вы двигаете мышью и видите стрелки на персонаже:

- **Зелёная (FA) длинная, голубая (скорость) короткая** → персонаж разгоняется
- **Зелёная направлена назад** → FA тормозит (автоторможение или отпустили мышь)
- **Оранжевая (коррекция) большая** → сильный боковой снос, FA компенсирует
- **Голубая и зелёная в разных направлениях** → персонаж дрейфует (скольжение)
- **Все стрелки маленькие** → персонаж почти стоит, FA в режиме «холостой ход»

## Объекты на трассе

| Вид | Тип | Что делает |
|-----|-----|------------|
| Серый круг | Столб (pillar) | Отталкивает при столкновении |
| Красный круг | Шип (spike) | Контакт = смерть → 0.8 с замораживание → респаун на старте |
| Пунктирный круг | Проход (passage) | Парные столбы с зазором. Мягкое отталкивание (0.5× упругости) |
| Голубая область | Зона «Лёд» | Снижает трение → больше скольжения |
| Коричневая область | Зона «Грязь» | Увеличивает трение + снижает скорость |
| Оранжевая область | Зона «Турбо» | Ускоряет в направлении движения |
| Голубой движущийся круг | Орб | Отскакивает от всех объектов; уничтожается при контакте с шипами |
| Зелёный пунктирный круг | Старт | Точка респауна (внизу карты) |
| Чёрно-белая клетчатая полоса | Финиш | Касание полосы → экран финиша с временем, рекордом, дистанцией |

## Важно для AI-ревьюеров

BonkLab — это **dev-only инструмент**, а не часть игры Bonk Race. При ревью кода:

1. **`client/src/lab/`** — код BonkLab. Не путать с основным клиентом (`client/src/main.ts`, `client/src/raceMain.ts`).
2. **`shared/src/physics/`** — общая физика. Используется и BonkLab, и сервером, и основным клиентом. Изменения здесь влияют на всё.
3. **Физика 60 Hz** — BonkLab работает на 60 Hz (`FIXED_DT = 1/60`), сервер — 30 Hz. Это сознательное решение для визуальной плавности.
4. **Death/respawn** — только spike-контакт. Нет HP, урона по зонам. Респаун полностью сбрасывает FA-состояние.
5. **Export/Import** — полный конфиг (`lab.params`), не дельта. Round-trip гарантирован.
6. **Заблокированные параметры** — `reverseZoneAngleDeg` отображается, но `disabled`. Не реализован в движке.
7. **Отдельный Vite entry point** — `/lab` не попадает в production build. Есть `npm run build:lab`.
8. **Орбы** — голубые движущиеся объекты, отскакивают от всех препятствий. Уничтожаются шипами (если включен spikeKill). Параметры в группе «Орбы».
9. **Грязь (бывш. «Слизь»)** — зона переименована из «Слизь» в «Грязь», цвет коричневый (был зелёный). Механика не изменилась: повышенное трение + снижение скорости.
10. **Турбо** — теперь ускоряет в направлении движения (ранее просто повышал лимит скорости). Цвет оранжевый (был жёлтый).
11. **Финиш** — касание клетчатой полосы вызывает экран финиша с итоговым временем, рекордом и пройденной дистанцией.
