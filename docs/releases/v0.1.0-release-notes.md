## Что такое BonkLab

BonkLab — dev-only песочница для настройки физики движения персонажа в Bonk Race. Отдельная страница (`/lab`), ~50 параметров, real-time редактирование, export/import JSON, 6 пресетов.

**Деплой:** GitHub Pages (автоматический через CI)

---

## Включено в релиз

### BonkLab v1.0 (Sprint 1b)

- 60Hz fixed-step physics simulation (Newtonian, F=ma, semi-implicit Euler)
- Flight Assist system (~25 параметров: линейное, угловое, drift compensation, damping)
- Canvas 2D renderer: camera follow, force vectors, minimap
- TelemetryHUD: 9 показателей в реальном времени
- Parameter panel: ~45 параметров в 13 группах
- Toolbar: restart, seed, density, reset, export/import, 6 presets
- Arena generator: deterministic (seed-based), density-driven
- Death/respawn: spike contact → 0.8s freeze → respawn
- Passage restitution: отдельный параметр (default 0.5×)
- Separate Vite entry point, not in production bundle

### BonkLab v1.2 (Sprint 2)

- **Орбы** — баллистические cyan-объекты: drag, collision resolution (orb-orb, orb-player, orb-obstacle, orb-wall), spike kill с анимацией смерти, детерминизм от seed
- **Настраиваемая геометрия трассы** — pillarRadius, spikeRadius, passageRadius, passageGap (перегенерация при изменении)
- **Финиш** — circle-vs-AABB касание клетчатой полосы, overlay с временем/дистанцией/рекордом
- **Камера** — персонаж на 65% от верха (больше обзора вперёд)
- **Прогресс и дистанция** — HUD: метры, процент
- **Пресет-трекинг** — dropdown показывает активный пресет, «Custom» при ручном изменении
- **Пресет «Ультралёгкий»** — mass=20, thrust=80000, speedLimit=500, drag=0.001
- **Rename slime → mud** — коричневый цвет, полный rename по всем слоям
- **Turbo rework** — accelBoost × mass в направлении скорости
- **Смерть** — сброс таймера, «Go!» overlay 0.8с

### Shared physics (переиспользуется BonkLab и основной игрой)

- `resolveCircleCircleCollision()` — elastic collision
- `resolveCircleStaticCollision()` — circle vs static obstacle
- `resolveWallCollision()` — boundary walls
- `arenaGenerator` — deterministic arena with zones, obstacles, passages, orbs
- `Rng` — seeded PRNG

## Известные ограничения

- BonkLab — dev-only, не включён в production bundle
- O(n²) orb-orb collisions при count > 50 может просаживать FPS
- `reverseZoneAngleDeg` заблокирован в UI (не реализован в движке)
- STARTUP_PRESET дублируется в main.ts и LabToolbar.tsx
- Zone modifier имеет 1-tick application lag (architectural)
