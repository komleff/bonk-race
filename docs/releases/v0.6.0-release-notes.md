## Обзор

Устранение визуального дёрганья (jitter) в BonkLab после внедрения анизотропного трения (v0.3.0). Проблема была не в физике, а в архитектуре цикла рендеринга: два независимых RAF-цикла и отсутствие интерполяции между дискретными тиками физики.

## Что нового

### Единый цикл рендера

- Удалён внутренний `requestAnimationFrame` из BonkLab
- Единственный RAF-цикл в `main.ts`: input → physics → render
- Публичный `update(frameDtSec): alpha` заменяет приватный `loop()`

### Интерполяция между тиками физики

- `getInterpolatedState(alpha)` — линейная интерполяция позиции, скорости, угла
- `lerpAngle()` — корректная интерполяция через ±π (кратчайшая дуга)
- `syncPrevState()` — защита от артефактов при телепортации:
  - Конструктор, `start()`, `reset()`
  - Смерть → респаун, respawnCountdown → 0
  - Spike-death (немедленная смерть)

### Защита от аномальных значений

- `Number.isFinite()` guard в `update()` — защита от NaN/Infinity
- `Math.max(0, ...)` — защита от отрицательного dt
- Alpha clamped в [0, 1] в `getInterpolatedState()`
- distanceM/progressPct пересчитываются по интерполированной позиции

### Плавный рендеринг следов

- `drawTrail()` переписан: обход ring buffer по возрасту (от старых к новым)
- Непрерывная per-point альфа вместо дискретного квантования
- Правильный z-порядок: тусклые (старые) точки под яркими (новыми)

### UI

- Версия приложения отображается в тулбаре BonkLab
